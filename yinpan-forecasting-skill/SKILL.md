# 阴盘奇门三家经验蒸馏推理（yinpan-forecasting）

本技能把王凤麟、杨忠易、李志强（奇门老李）三家阴盘奇门的蒸馏经验整理成可直接调用的
规则库，用于：断局分析、取象取舍、流派冲突仲裁、运筹化解方案检索、断局收尾校验。
它**不重复排盘计算**（排盘走 `forecasting` 技能的 `scripts/qimen_cli.py` 或既有盘面），
只负责“拿到盘面之后怎么断、怎么取舍、怎么化解”。

## 三家体系速览（先定视角）

| 维度 | 王凤麟 | 杨忠易 | 李志强 |
|---|---|---|---|
| 第一抓手 | 四害空亡＞转宫翻宫＞用神＞隐干＞八神 | 引干＞用神＞空亡转宫 | 日干六亲、十二长生＞空亡；引干隐干辅助 |
| 翻宫 | 可多层深挖因果，伏吟反吟都可翻 | 最多一层，不叠多层 | 优先本宫+对宫生克联动，必要才翻一层 |
| 转宫 | 在场/不在场两套二分 | 统一单次，不分在场 | 统一单次，不分在场 |
| 四害 | 可量化（入墓击刑约剩2成） | 定性阻滞消耗 | 定性＋十二长生看进退 |
| 运筹 | 移星换斗，换宫换象，强干预 | 改因果链路、人事沟通，无道具 | 极简方位趋避，顺势借力轻道具 |
| 擅长 | 隐情深挖、调理布局 | 人事合作纠纷、因果链 | 六亲、寻物、日常百事 |
| 盲区 | 应期偏弱、象意发散、转宫易记混 | 缺风水布局、依赖求测人配合 | 无主动换局、缺暗中小人专项 |

**不要硬揉三家为一套**：断局与运筹模块分离，按案子场景调取最合适的体系作为主判链，
另两家作旁参对照。

## 断局优先级链（焊接死的总纲）

1. **先走【融合断局流水线】固定 12 步**，不跳步。
2. **定问事类型**：家庭婚恋亲属寻物人际纠纷 → 老李六亲+长生；合作中间人牵线纠纷 → 忠易引干。
3. **检查空亡转宫**为第一开关（第一优先级）；普通测事先空亡，中间人牵线先引干。
4. **大局标伏反吟**定快慢节奏（伏吟慢僵持、反吟快反复），再进细节读象。
5. **本宫读象**（星门仪隐干八神＋四害），附加十二长生加权。
6. **翻宫取舍**：能本宫对宫生克看清就不翻；常规一层，陈年纠缠最多两层。
7. **梳理关系**：引干/用神/目标宫对冲、相合、牵绊；八神看心念，必要外应校验。
8. **输出第一层结论**：现状、卡点、趋势、成败概率。
9. **运筹分流（可选）**：客户不问化解不启动；要化解先走运筹调用顺序。
10. **过一遍【避坑清单】再定稿**。

具体每一步的操作问题与示例见 `references/融合断局流水线.md`。

## 冲突取舍主线（可执行策略）

遇到三家观点冲突时，按 `references/冲突取舍库.md` 的 C01–C16 逐条匹配，采用每条记录的
“我的取舍主线”，并以“触发备注”作为切换条件。核心主线示例：

- 空亡转宫：优先确认求测人当面/视频/文字，再选凤麟在场/不在场路线。
- 翻宫：常规一层、陈年纠缠两层；能对宫生克看清就不翻。
- 核心线索：空亡转宫第一开关、引干第二线索；中间人牵线先引干；六亲人事寻物切老李视角。
- 甲年命：看值符宫（凤麟）；局中出现甲干非年命一律本宫读。
- 四害：定性为主，不强制套百分比。
- 化解方向：区分场景调取工具箱，断局不受运筹影响；运筹属附加项。
- 化解能否逆势：先忠易判断因果是否已锁定；已定则弃强力运筹，只用老李趋避减损。
- 摆件：优先无道具方案（忠易人事、老李方位行动）；客户主动要布局再调凤麟移星。
- 心念：采信忠易作前置校验——运筹前先确认求测人愿改想法、配合行动，否则不做布局化解。
- 伏吟反吟：先定节奏快慢再进细节；伏吟运筹第一层先老李走动引马星。
- 寻物：专项启用老李三层流程（能否找回→在哪→谁拿的），最后凤麟外应复核。

## 运筹化解调用顺序（低成本→高成本）

1. 先忠易评估：因果是否已定型、大局是否衰败、求测人是否愿配合。
2. 因果已定 / 大势已坏 → 不做强力化解，只用老李趋避减损、劝止损。
3. 机会尚存、愿配合 → 按低成本到高成本调用：
   **① 忠易人事调整（换对接人/延后时间/改诉求表达）→ ② 老李方位择时行动（引马星/换座位）→ ③ 凤麟移星换斗布局（择时+外应+空间）**。
4. 多重凶叠加、空间受限、求测人不愿调整想法 → 退回低阶方案或只做疏导。

详见 `references/运筹化解元规则库.md`（O-F01~F02 凤麟、O-Z01~Z02 忠易、O-L01~L03 老李、O-FZL01 融合调用顺序）。

## 读象规则与元规则

- 断局元规则按 `references/断局元规则库.md` 的 Y-F01~F04（凤麟）、Y-Z01~Z03（忠易）、
  Y-L01~L05（老李）、Y-FZ01~FZ02（三家共识）逐条匹配，每条含 适用场景/要素组合/约束条件/解读趋势/反例坑。
- **反例坑是校验重点**：同一符号多义必须标触发条件，不得把象当固定标签。

  核心偏好、特有口诀象意、断事流程、运筹体系、盲区限制。

## 断局收尾必做：过避坑清单

每次定稿前对照 `references/避坑清单.md` 7 条校验：不混底盘范式、不迷信单一格局、不把象当
固定标签、不用事后能解释的模糊断语、不优先级混乱、不用本书旺衰口径套别家结论、规则库及时去噪。

## 与 `forecasting` 技能的协作

- `forecasting`（仓库根目录）：负责访谈、排盘计算（`scripts/qimen_cli.py`）、九宫格渲染、终身盘。
- `yinpan-forecasting`（本目录）：拿到盘面后，用三家蒸馏经验做断局推理、冲突取舍、运筹化解与避坑校验。
- 建议调用顺序：`forecasting` 先完成访谈与排盘 → 将盘面关键字段传入本技能 → 本技能按上文
  断局优先级链与冲突取舍主线完成解读与化解方案。
