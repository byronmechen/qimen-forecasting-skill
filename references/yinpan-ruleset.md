# daoist-yinpan 规则集（道家阴盘奇门）

规则已用 6 个实盘（66 项断言）通过脚本回归验证（`scripts/test_yinpan.py`）。

## 与 mainline-cn-v1 的区别

本规则集与 mainline-cn-v1 在定局（数字公式 vs 节气三元置闰）、值使飞宫、隐干、马星、空亡转宫/翻宫上均不同，两套规则**不可混用**。用户没有指定流派时先问；提到"阴盘、道家奇门、隐干、转宫"等词一律用本规则集。

## 定局

- 冬至后夏至前 = 阳遁；夏至后冬至前 = 阴遁。
- 局数 =（年支序数 + 农历月数 + 农历日数 + 时支序数）÷ 9 取余，余 0 作 9。
  - 支序：子1 丑2 寅3 … 亥12。年支取农历年（正月初一换年）。
  - 例：丙戌年（戌11）四月廿六 庚戌时（戌11）：11+4+26+11=52，52%9=7 → 阳七局。
- 闰月按同名月的月数计算（脚本会给 warning，宜向用户说明）。

## 排盘要点（脚本已实现，此处供核对与讲解）

1. 地盘：戊己庚辛壬癸丁丙乙，阳局从局数宫顺布（宫数+1），阴局逆布。
2. 旬首六仪：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。
3. 值符 = 旬首地盘落宫之星，值使 = 该宫之门；旬首落中宫则值符为天禽（随天芮转）、值使为死门。
4. 值符与旬首仪随时干转：落到时干地盘宫（中宫寄坤），九星、天盘干整环随转；坤宫天盘干与中宫寄干成对随行（盘面出现双干）。
5. 值使门落宫：从旬首宫按**宫数**阳顺（+1）阴逆（−1）数至当前时辰，含中 5 宫（落 5 寄坤）。八门从值使门宫起**永远顺时针**布。
6. 八神：值符落时干宫，阳遁顺时针、阴遁逆时针：符蛇阴合虎玄地天。
7. **隐干（暗干）**：把地盘盘面沿八宫环从时干宫**刚性旋转**到值使门宫（坤宫双干成对随行）。时干宫与值使宫重合＝暗干伏吟，隐干与地盘重合，另用"求变入中"：时干入中 5 宫，其余按戊己庚辛壬癸丁丙乙接续，阳遁按 1,2,3…宫、阴遁按 9,8,7…宫排。
8. 空亡：按时旬空亡地支标宫（子→坎、丑寅→艮、卯→震、辰巳→巽、午→离、未申→坤、酉→兑、戌亥→乾）。
9. 马星：亥卯未时在巽、申子辰时在艮、寅午戌时在坤、巳酉丑时在乾。

## 刻盘（刻家）

规则已用两个实盘全宫位校准（含一个暗干伏吟局），另用 6 个刻盘实盘交叉验证，全部入回归测试。

- **刻柱**：一时辰十二刻、每刻 10 分钟。刻干支从**时干五鼠遁起子刻**（甲己起甲子、乙庚起丙子、丙辛起戊子、丁壬起庚子、戊癸起壬子），沿六十甲子顺排。
- **定局**：局数 =（年支序 + 农历月 + 农历日 + 时支序 + **刻支序**）% 9，余 0 取 9。
- **刻柱顶替时柱**：旬首、旬空、值符值使飞宫、盘面"时干"、马星均按刻柱。
- **暗干伏吟**（值使宫与刻干宫重合）：隐干**跳三宫**——隐干(宫n) = 地盘(宫n+3)，即 1←4←7、3←6←9、2←5←8；中宫(5)的隐干寄坤显示。与时盘"求变入中"不同。
- **六亲移位**（明文规则）：舍掉原年干——月干作年干、日干作月干、时干作日干、刻干作时干，取用神按移位后坐标。
- 调用：输入 JSON 加 `"pan_type": "ke"`；输出 `chart.ke` 含刻柱、第几刻、刻旬首、刻旬空、原时柱。
- 注意：交叉验证盘例中另有 3 个"辛巳时第二小时"的盘刻柱比本规则 +1 刻（排盘工具差异），以全宫位校准结果为准。起局时间距刻界 ≤1 分钟时脚本给 warning。

## 脚本调用

输入 JSON 与 mainline 相同，`ruleset` 填 `"daoist-yinpan"`：

```json
{"question_type": "…", "question_goal": "…", "time_input": "2026-07-12 15:30", "calendar_type": "solar", "location": {"country": "中国", "city": "…", "timezone": ""}, "ruleset": "daoist-yinpan"}
```

输出新增/变化字段：

| 字段 | 含义 |
|------|------|
| `chart.ju_formula` | 定局公式各分量（复核用） |
| `chart.horse_palace` | 马星落宫 |
| `chart.zhifu.home_palace` | 值符星本宫（旬首地盘宫） |
| `chart.zhishi.palace` / `hosted_palace` | 值使门落宫（原始/寄坤后） |
| `chart.palaces[].sky_stems` | 天盘干（数组，坤宫可能双干） |
| `chart.palaces[].hidden_stems` | 隐干（数组） |
| `chart.palaces[].is_kongwang` / `has_horse` | 该宫空亡 / 马星标记 |
| `chart.fuyin_hidden` / `hidden_qiubian` | 暗干伏吟标记 / 求变入中盘 |
| `chart.zhuan_gong.present` / `absent` | 空亡转宫表（人在面前/不在面前） |

## 已知边界

- 卦身/入中数未实现（实际解读中几乎不用）。
- 晚子时（23 点后）农历日取值有歧义，脚本给 warning，宜和用户确认。
- 年支在立春—正月初一之间存在换年歧义，公式按正月初一。
