# 阴盘奇门终身盘（奇门命理盘）

终身盘是人出生那一刻天地能量磁场的组合，代表先天之命；后天之运看大运流年与个人努力（行为风水、解四害）。

## 一、起盘

- 按**出生时刻**起时家阴盘，定局公式、排盘规则与测事盘完全相同（`chart_scope: "life"`，仅支持时盘）。
- 出生时间至少确定到时辰；时辰不确定不排终身盘，可建议先用生活重大事件反推时辰（人工流程，不入脚本）。
- 农历出生要确认闰月；23 点后出生注意晚子时日数（脚本有 warning）。
- 出生地在海外须补时区，按出生当地时间起局。
- **夏令时**（如中国 1986-1991）：脚本自动折回标准时排盘并给 warning，解读时要向用户说明。

## 二、取用神（与测事盘同坐标，侧重不同）

终身盘找用神：**年干、日干在天盘的落宫**为核心。

| 柱 | 终身盘含义 |
|----|-----------|
| 年干 | 祖上/父母/领导；个人**根基、天赋、使命**（与日干并看个人能力） |
| 月干 | 兄弟姐妹/平辈；门户 |
| 日干 | **命主自己**（性格、能力、一生主线） |
| 时干 | 子女/事业平台/晚运 |

- 配偶：日干**相合之干**（甲己、乙庚、丙辛、丁壬、戊癸）落宫；泛看婚姻乙=女、庚=男。
- 财运：生门＋戊（资本）；生门空看对宫。
- 事业官运：开门；克日干之干落宫为官。
- 身体：按十干对应部位查四害宫（见 yinpan-duanbing.md）。
- 脚本 `chart.life.pillars` 给出四柱每柱的入盘干（甲按本柱旬首遁仪）及天盘/隐干/地盘落宫。

## 三、判断好坏：四害（层级：门迫＞击刑＞入墓＞空亡）

用神宫及各宫先查有无四害，脚本 `chart.life.sihai` 已逐宫检出：

1. **门迫**：门克宫。开/惊（金）迫震巽；休（水）迫离；生/死（土）迫坎；伤/杜（木）迫坤艮；景（火）迫乾兑。事情打折扣、有冲突损伤。
2. **击刑**（六仪击刑，查天盘与地盘干；中宫寄坤干并入坤2）：戊落震、己落坤、庚落艮、辛落离、壬落巽、癸落巽。主伤病、错乱、错误。
3. **入墓**（十干墓库，查天盘与地盘干；隐干不查，app 实盘校准）：甲癸墓坤（未）、乙丙戊墓乾（戌）、丁己庚墓艮（丑）、辛壬墓巽（辰）。能量只发挥 20%，力使不出。
4. **空亡**：信息二八开，按 `zhuan_gong` 转宫参看（规则同 yinpan-jiepan.md）。

用神宫无四害、气旺相 → 格局高；四害叠加、气衰 → 该领域一生费力，需解化。

## 四、气之旺衰定格局

以**出生月令**衡量各宫五行旺衰（脚本 `chart.life.wangshuai`）：当令旺、令生者相、生令者休、克令者囚、令克者死。

- 日干/年干落宫**旺相且无四害**：先天格局高，天赋能用得出来。
- 落宫休囚死又带四害：对应领域先天薄弱，重在后天调理与规避。
- 课程口径：先看有无四害定好坏，再以旺衰定格局高低，最后才做具体预测。

## 五、镜像断法（对宫、先后天宫）

具体预测像照镜子：一宫之事参看**对宫**与**先后天宫**。

- 对宫：坎↔离、坤↔艮、震↔兑、巽↔乾（脚本 `chart.life.mirror.dui_gong`）。
- 先后天宫：沿用 `zhuan_gong` 两表（present=后天成像，absent=先天卦宫）。
- 用神宫信息不足或逢空，从镜像宫补读。

## 六、大运与流年

- **流年**：看**太岁地支落宫**（书例：酉年看酉宫）。流年宫的天地盘干、星门神与命主宫的生克关系 = 当年吉凶主线；白虎、螣蛇等凶神落流年宫为阻隔、反复之象。脚本 `chart.life.liunian` 给出年份→干支→落宫（默认今年起 10 年，可传 `liunian_years` 指定）。注意：脚本按公历年粗取干支，未按立春切分，边界年份人工确认。
- 流年应期仍用填实、逢冲（yinpan-zeri.md）。
- **大运**（已按实盘校准，2026-07-14）：八字式排法——月柱起，阳男阴女顺排、阴男阳女逆排；顺数至下一节/逆数至上一节，**天数舍尾取整、3 日折 1 年、1 日折 4 月**，首运年=起运日所在公历年；起运前月柱段年份标签用干支年（立春前出生归上一年），十年一运，附干支两字十神（天干+支本气，以日干为我）。脚本 `chart.life.dayun` 输出方向、起运岁数、十段列表（首段为起运前月柱期）；未提供性别不排。解读：大运干支落宫（支按 BRANCH 落宫、干看天盘落宫）与命主宫生克 = 十年主线，流年在大运框架内看。

## 七、解读输出纪律

- 顺序：先天格局（日干、年干宫）→ 各领域宫位（婚姻、财、事业、健康、子女）→ 四害与解化建议 → 近年流年。
- 一次解读聚焦用户最关心的 2–3 个领域，不逐宫流水账。
- 解四害方向（课程口径）：活砂（贵人）、忏悔、加强乙丙丁三奇与天蓬/天辅/天心，配合行为风水（yinpan-fengshui.md，一次最多调三宫）。
- 终身盘不下宿命定论：不断寿、不断死、不说"命中注定无解"；凶信息表述为"哪个领域、哪个年份段需要防范什么"。
- 健康部分只做参考观察，附"以医院检查和医生意见为准"。
